# icamago/.github

Organization-wide default community health files for `icamago`.

GitHub applies these issue and pull request templates to every repository in the
organization that does not define its own. To customize templates for one
repository, add them to that repository's `.github/` directory; doing so
replaces these defaults for that repository.

This repository must stay public for GitHub to apply the defaults. Keep it free
of code, secrets, and internal details.
